# SAIM // FRONT-END ARCHITECT & CREATIVE PORTFOLIO

> High-end, brutalist cyberpunk editorial portfolio engineered with React 19, Vite, Tailwind CSS, Framer Motion, and zero-dependency Web Audio API procedural synthesis. Inspired by the editorial spatial language of Curtis Nguyen.

---

## ⚡ ARCHITECTURAL SPECIFICATIONS

- **Core Engine**: React 19 + Vite 6
- **Styling Architecture**: Tailwind CSS + Custom CRT phosphor raster matrices
- **Motion & Physics**: Framer Motion fluid spring transitions
- **Acoustic Synthesizer**: Zero-dependency procedural Web Audio API (`soundEngine.js`)
- **Spatial Viewport**: 100vh Viewport-locked 4-stage presentation deck
- **Resolution Support**: Tested across 320px Mobile, 768px Tablet, 1080p Desktop, and 2560px Ultrawide

## ⌨️ TACTICAL COMMANDS & SHORTCUTS

| Input Trigger | Target Action |
| :--- | :--- |
| **`Wheel Down` / `ArrowDown` / `Space`** | Advance to next deck stage |
| **`Wheel Up` / `ArrowUp`** | Return to previous deck stage |
| **`ArrowLeft` / `ArrowRight`** | Carousel through verified projects (01–09) |
| **`[ MENU ]` / `Esc`** | Toggle / dismiss tactical fullscreen navigation matrix |
| **`SOUND [ON/OFF]`** | Toggle procedural Web Audio synthesizer |
